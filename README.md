# Global Service Inventory Optimization

**MSBA Capstone Project | Zebra Technologies | January 2026 – May 2026**

## Project Overview

This capstone explored how analytical modeling can support inventory-planning decisions across a global service network. The work focused on balancing product availability, operational efficiency, and customer-service objectives.

Because this project was completed under a confidentiality agreement, proprietary data, internal results, source code, and detailed business recommendations are not included in this public repository.

## Business Questions

* How can organizations determine appropriate inventory targets across products and service locations?
* How can inventory investment be balanced against service-level requirements?
* Which operational dependencies should be considered when implementing optimized inventory policies?
